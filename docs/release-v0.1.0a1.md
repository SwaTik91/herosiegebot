# v0.1.0a1 — Windows test preview

Первый тестовый релиз vision-based фармбота Hero Siege.

## Включено

- захват безрамочного окна через dxcam;
- автоматический поиск HUD и мини-карты;
- FOW/frontier-навигация по процедурной карте;
- распознавание состояния через OpenCV;
- управление WASD, ЛКМ, `Q/E`, `1/2` через `SendInput`;
- обязательная аварийная остановка `F12`;
- безопасная пауза при потере фокуса, окна или калибровки;
- dry-run, оверлей, JSONL-диагностика и сбор кадров;
- 161 офлайн-тест с покрытием 85%.

## Ограничения

- Windows и Hero Siege ещё не прошли живую приёмку.
- В релиз не входят проверенные шаблоны `enemy`, `loot`, `death`, `restart`.
- Автоматический ввод намеренно не запускается без этих шаблонов.
- Поддержка разрешений и UI scale подтверждается только после Windows-калибровки.

Начните с `README.md`, затем выполните `docs/windows-smoke-test.md`.

# v0.1.0a2 — Windows emergency-hotkey correction

Этот релиз заменяет `v0.1.0a1`.

## Исправлено

- аварийная остановка перенесена с `F12` на точную комбинацию
  `Ctrl+Shift+F10`;
- комбинация регистрируется через `RegisterHotKey` с флагами
  `MOD_CONTROL | MOD_SHIFT | MOD_NOREPEAT`;
- ошибка регистрации синхронно прерывает запуск и сообщает числовой код
  `GetLastError`;
- сохранены fail-closed запуск, освобождение ввода при остановке и изоляция
  исключений callback.

`F12` нельзя использовать для обязательной аварийной остановки: Microsoft
резервирует эту клавишу для отладчиков, поэтому `RegisterHotKey` может
возвращать ошибку даже без конфликта с другим приложением. Низкоуровневые
клавиатурные хуки не используются.

Windows-приёмка и 30-минутный прогон по-прежнему не выполнены. Перед включением
ввода пройдите `docs/windows-smoke-test.md`.
